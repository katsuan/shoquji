# 🍚 しょくじ 〜ShoQuji〜

食べたものとカロリー・PFC（たんぱく質・脂質・炭水化物）をさっと記録して、1日の合計や1週間のふりかえりを見られるツール。名前は「しょくじ」。英字は ShoQuji（「しょ・く・じ」の「く」を Q にする。くじ＝Qji・おくるん＝OQRN と同じ作り方）。GitHub Pages でそのまま動く静的サイト。ブラウザでは記録はこの端末の中だけ、LINE の中で開くと食事記録ボット（GAS）のシートにも残る。

公開URL: https://katsuan.github.io/shoquji/

## できること

- 📝 記録する：日付（きょう・きのう・ほかの日）、朝・昼・夜・間食（タブ。選んでいる食事の色の枠で、食べたもの〜栄養までを囲む）、食べたもの。カロリー・PFC は「栄養も入れる」を開いて入れる（入れなくても記録できる）
  - 🍚 ご飯何杯分？：だいたいのカロリーをボタンで入れる（くらぶボットと同じ目安。ご飯1杯（150g）≈ 240kcal。朝・昼・夜は½〜3杯、間食は 🍬少し（80kcal）〜1.5杯）。もう一度押すと取り消し、自分で数字を入れると選んだ印が外れる
  - 前に食べたものは、よく食べる順に丸いボタンで出る。押すと名前と、最後に入れたカロリー・PFC が入る。字を入れると絞りこむ
- 🍽 この日のしょくじ：合計カロリーと目標（バー。朝・昼・夜・間食の色で積む。目標をこえたら赤いふちと目標の線）、食事ごとのカロリーと割合（%）、PFC の合計と目標、食事ごとの一覧。名前を押すと直せる、✕ ですぐ消せる（下に出る知らせの「元に戻す」で戻せる）
- カードで送る（おくるんのマーク）：おくるんのお知らせカード（`https://liff.line.me/<LIFF ID>/card/`）に、日付・合計カロリー・食事ごとの名前・PFC を渡す。色はロゴの黄色（#EC8A16）、ボタンは「🍚 しょくじで記録する」。流入口は `from=shoquji`
- 📝 記録用の文字も送る（カードで送るボタンの下。この端末に覚える。はじめはオフ）：オンにすると、カードの後ろに次の文字も1通送る。LINE のボットにはカードの中身が届かないので、個人用の食事記録ボット（line-meal-project の GAS。`gs/04_usecase/04_usecase.shoquji.gs`）がこの文字を読んで記録する。おくるんのカードには `sendText=` で渡す
  ```
  #しょくじ 2026/10/22
  朝 トースト 250kcal P8 F6 C40
  昼 カレーライス 780kcal
  ```
- 📈 ふりかえり：続けて記録した日数、1週間のカロリー（目標の線つき。棒は朝・昼・夜・間食の色を下から積む）、この7日の朝・昼・夜・間食の割合（カロリーを入れた日の1日平均も）、よく食べるもの
- 朝・昼・夜・間食の色：朝＝黄 `#f5bf26`・昼＝緑 `#36a55a`・夜＝藍 `#5a55d2`・間食＝ピンク `#e3609a`（`style.css` の `--meal0`〜`--meal3`。PFC の赤・黄土・青と見分けやすい色）。入力の食事のボタン・一覧の札・バーで同じ色
- ⚙️ 目標・記録の控え：1日の目標、控えの書き出し（スマホは共有シート、パソコンはダウンロード）・読みこみ（同じ記録は新しいほう、ほかは足す）、すべて消す

## 記録の置き場所

この端末（ブラウザ）の localStorage の `shoquji:v1` だけ。ブラウザで開いたしょくじは、サーバーには送らない（LINE の中でつないだときだけ、下の「食事記録ボットとつなぐ」）。

- 記録 1件 = `{ id, date: "YYYY-MM-DD", meal: "朝"|"昼"|"夜"|"間食", name, kcal, p, f, c, at, upd }`（数字は入れなかったら null）
- `upd`（最後に直した時刻）と、消した記録の id（`deleted`）は、あとで「自分の GAS につなぐ」ときに、端末とサーバーの記録をそろえるために残している

## 食事記録ボットとつなぐ（くわしい人向け）

LINE の中（LIFF）で開いたしょくじだけ、自分の食事記録ボット（line-meal-project の GAS。リポジトリは非公開。配布用シートのコピー）とつなげる。つくりは、つづく（q-tuzuq）のつなぐしくみを写したもの。

- 画面：「⚙️ 食事記録ボットとつなぐ（くわしい人向け）」のたたみ欄。GAS の URL（`…/exec`）を入れる欄は LINE 版のときだけ出る。形がちがえば赤字。つないでいるあいだは、この日のしょくじの下に「LINE で開いたしょくじの記録は、ブラウザとは別」と出す。LINE のアプリ内のブラウザ（LIFF でない形）で開いたときは「LINE のしょくじで開きなおす」
- 記録すると、ボットのシートにも1行入る（`submitMealBatch`。しょくじの記録の id を `clientId` として送り、同じ id は何度送っても1回だけ）。つながったときに、まだ送っていないここ7日の記録も送る（送った id は `sent`）
- 開いたとき・戻ってきたとき（1分に1回まで）に、ボットに入っている60日分の記録を読む（`listMealLogs`）。しょくじから送ったもの・しょくじで消したものは出さない。ボットのトークで送った記録は「ボット」の札で出す（端末の記録には足さず、控えは `shoquji:bot`）
- 「ボット」の記録を押す・カードの「画面で詳しく」（`logId`）から開くと「ボットの記録を直す」：「✏️ 直す」でボットのその記録を直す（`updateMealLog`。カロリーは要る。MYメニューにも保存）。端末の記録はふやさない
- カードの「MYメニューを直す」（`masterKey`）から開くと「MYメニューを直す」：「📒 MYメニューに保存」で MYメニューだけ保存（`saveNutritionMasterOnly`）
- 送るのは LIFF の ID トークンと記録だけ（userId は送らない。トークンは残さない）。つなぎ先は自分で入れた URL だけ
- LIFF の ID は `js/line-config.js`。くらぶボット（Q のプロバイダー。つづくと同じチャネル）の LIFF（`2012187502-BVvVhWZM`。前は食事記録ボットの `2010088825-CulmmaFc`。エンドポイントを `https://katsuan.github.io/shoquji/` にする）。この LIFF で開いたときは、つなぎ先を入れなくても食事記録ボットにつながる（`gasUrl`）。ボットのカード・リッチメニューの指定（`?mode=…&meal=…&menu=…&logId=…`）も受ける
- つなぎ方は `docs/linelog-setup.html`（配布用シート「食事記録 しょくじ版（配布用）」のコピーから5手）
- ブラウザで開いたときは、この日のしょくじの下に「📱 LINE 版で使う」（LINE で開く案内と4コマ。つづくと同じ作り）。閉じたらその端末では出さず、「⚙️ 食事記録ボットとつなぐ」の「👀 使い方（4コマ）を見る」でまた出る
- ボットの記録を読んだとき、しょくじの自分の記録（`clientId` のある行）とくらべてずれていたらそろえる（`planSync`）：しょくじで消したのにボットに残っている行は消し、中身がちがえばあとから直したほう（しょくじの `upd`・ボットの `updatedAt`）に合わせる。画面の合計とボットのカードの合計が同じになるように
- 自分の記録を直す・消すと、ボットにもそろえる（id＝`clientId` で `updateMealLog`・`deleteMealLog`。カロリーがなくてもよい）。消すのは「元に戻す」を押せる6.5秒が過ぎてから送る（閉じる・切りかえるときは、すぐ送る）
- 「ボット」の記録にも ✕。押すと画面から先に消し、「元に戻す」の時間が過ぎてからボットから消す
- 開いたときに、ボットの目標・20時のお知らせ・よく記録するもの・MYメニューを読む（`getLiffAppState`）。目標カロリーはボットの値にそろえ、変えたらボットにも送る（`updateProfile`）。「🔔 20時に、記録がない日は LINE でお知らせ」は「⚙️ 目標・送り方・記録の控え」の中
- 名前の欄の候補には、つないでいるとき MYメニュー（ボットの栄養の表）の品も出る（押すとカロリー・PFC が入る）
- MYメニューは「共通」（管理者が整える）と「自分の」に分かれている。欄の一覧には「共通／自分」の札。共通の品の「✏️ 自分用に」で、自分用の写しを作る（共通は変わらない。ボットの GAS が写しを作る。管理者は共通をそのまま直せる）
- MYメニュー・候補から数字を入れたときは、「量 ×½・×1・×1.5・×2」で、もとの数字に倍率をかけて入れなおせる（大盛り・半分など）
- 「📌 よく記録するもの・MYメニュー」で MYメニューをさがすと、品ごとに「📌 固定」「✏️ 直す」。「✏️ 直す」は入力欄に開いて「📒 MYメニューに保存」（しょくじにない種類・量・メモ・塩分・食物繊維は、前の値のまま送る）
- 「📌 よく記録するもの・MYメニュー」：固定する品（MYメニューから12品まで）の並べかえと、MYメニューをさがして直す。固定した品は、ボットの返事の下のボタン（クイックリプライ）に前から並ぶ。ボットのカードの指定（`mode=quick`）はここを開く（くらぶボットは、ひとりずつの「⚡ よく記録」のリッチメニューは作らない）

## つづくとの連動

つづく（q-tuzuq）の「しょくじ連動」の習慣は、同じブラウザのしょくじの記録した日に ○ が付く。しょくじは、記録がある日の一覧を localStorage の `shoquji:days`（`{ v: 1, days: [日付…] }`）にも書く（画面を描くたび。変わったときだけ）。ここには、端末の記録に加えて、LINE の中でつないでいるときの食事記録ボットで入れた記録の日も入る。つづくは `shoquji:v1` と `shoquji:days` の両方を読む。GitHub などへは、つづくが記録ボット（LOgBOT）に送る（しょくじからは送らない）。

## アイコン・ロゴ・OGP

`python3 tools/icon.py` で作る（図形を描く部分は、となりのおくるん（`~/GitHub/q-oqrn`）の `tools/brandkit.py`）。

- Q は上から見たお茶碗：白いふちが Q の輪、中にご飯と梅干し、右下へ出た2本のお箸が Q のしっぽ（お皿とお箸・満腹の顔の案とくらべて決めた）
- 横長のロゴ（`logo.svg`）：S・h・o・j・i は Jua、Q はお茶碗、u は 🍵 のような湯のみ（u の字の形を胴にして、緑のお茶と湯気）
- 色は玉子焼きの黄色（ほかの Q のツールと重ならない色）
