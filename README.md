# 🍚 しょくじ 〜ShoQuji〜

食べたものとカロリー・PFC（たんぱく質・脂質・炭水化物）をさっと記録して、1日の合計や1週間のふりかえりを見られるツール。名前は「しょくじ」。英字は ShoQuji（「しょ・く・じ」の「く」を Q にする。くじ＝Qji・おくるん＝OQRN と同じ作り方）。GitHub Pages でそのまま動く静的サイトで、サーバーは使わない。

公開URL: https://katsuan.github.io/shoquji/

## できること

- 📝 記録する：日付（きょう・きのう・ほかの日）、朝・昼・夜・間食、食べたもの。カロリー・PFC は「栄養も入れる」を開いて入れる（入れなくても記録できる）
  - 前に食べたものは、よく食べる順に丸いボタンで出る。押すと名前と、最後に入れたカロリー・PFC が入る。字を入れると絞りこむ
- 🍽 この日のしょくじ：合計カロリーと目標（バー）、PFC の合計と目標、食事ごとの一覧。名前を押すと直せる、✕ で消せる
- 💬 LINE で送る：おくるんのお知らせカード（`https://liff.line.me/<LIFF ID>/card/`）に、日付・合計カロリー・食事ごとの名前・PFC を渡す。色はロゴの黄色（#EC8A16）、ボタンは「🍚 しょくじで記録する」。流入口は `from=shoquji`
- 📈 ふりかえり：続けて記録した日数、1週間のカロリー（目標の線つき）、よく食べるもの
- ⚙️ 目標・記録の控え：1日の目標、控えの書き出し（スマホは共有シート、パソコンはダウンロード）・読みこみ（同じ記録は新しいほう、ほかは足す）、すべて消す

## 記録の置き場所

この端末（ブラウザ）の localStorage の `shoquji:v1` だけ。サーバーには送らない。

- 記録 1件 = `{ id, date: "YYYY-MM-DD", meal: "朝"|"昼"|"夜"|"間食", name, kcal, p, f, c, at, upd }`（数字は入れなかったら null）
- `upd`（最後に直した時刻）と、消した記録の id（`deleted`）は、あとで「自分の GAS につなぐ」ときに、端末とサーバーの記録をそろえるために残している

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html`・`style.css` | 画面と見た目（スマホ前提。入力欄は 16px 以上、ページにも背景色） |
| `app.js` | 操作（記録・直す・消す・カード・ふりかえり・目標・控え） |
| `js/store.js` | 記録の保存・控えの書き出しと読みこみ |
| `js/stats.js` | 計算（日付・合計・よく食べるもの・1週間・続けた日数） |
| `tools/icon.py` | アイコン・ロゴ・OGP |

## アイコン・ロゴ・OGP

`python3 tools/icon.py` で作る（図形を描く部分は、となりのおくるん（`~/GitHub/q-oqrn`）の `tools/brandkit.py`）。

- Q は上から見たお茶碗：白いふちが Q の輪、中にご飯と梅干し、右下へ出た2本のお箸が Q のしっぽ（お皿とお箸・満腹の顔の案とくらべて決めた）
- 横長のロゴ（`logo.svg`）：S・h・o・j・i は Jua、Q はお茶碗、u は 🍵 のような湯のみ（u の字の形を胴にして、緑のお茶と湯気）
- 色は玉子焼きの黄色（ほかの Q のツールと重ならない色）
