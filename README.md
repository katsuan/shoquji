# 🍚 しょくじ 〜ShoQuji〜

食べたものとカロリー・PFC（たんぱく質・脂質・炭水化物）をさっと記録して、1日の合計や1週間のふりかえりを見られるツール。名前は「しょくじ」。英字は ShoQuji（「しょ・く・じ」の「く」を Q にする。くじ＝Qji・おくるん＝OQRN と同じ作り方）。GitHub Pages でそのまま動く静的サイトで、サーバーは使わない。

公開URL: https://katsuan.github.io/shoquji/

## できること

- 📝 記録する：日付（きょう・きのう・ほかの日）、朝・昼・夜・間食、食べたもの。カロリー・PFC は「栄養も入れる」を開いて入れる（入れなくても記録できる）
  - 前に食べたものは、よく食べる順に丸いボタンで出る。押すと名前と、最後に入れたカロリー・PFC が入る。字を入れると絞りこむ
- 🍽 この日のしょくじ：合計カロリーと目標（バー）、PFC の合計と目標、食事ごとの一覧。名前を押すと直せる、✕ ですぐ消せる（下に出る知らせの「元に戻す」で戻せる）
- 💬 LINE で送る：おくるんのお知らせカード（`https://liff.line.me/<LIFF ID>/card/`）に、日付・合計カロリー・食事ごとの名前・PFC を渡す。色はロゴの黄色（#EC8A16）、ボタンは「🍚 しょくじで記録する」。流入口は `from=shoquji`
- 📝 記録用の文字も送る（LINE で送るボタンの下。この端末に覚える。はじめはオフ）：オンにすると、カードの後ろに次の文字も1通送る。LINE のボットにはカードの中身が届かないので、個人用の食事記録ボット（line-meal-project の GAS。`gs/3_usecase/3_usecase.shoquji.gs`）がこの文字を読んで記録する。おくるんのカードには `sendText=` で渡す
  ```
  #しょくじ 2026/10/22
  朝 トースト 250kcal P8 F6 C40
  昼 カレーライス 780kcal
  ```
- 📈 ふりかえり：続けて記録した日数、1週間のカロリー（目標の線つき）、よく食べるもの
- ⚙️ 目標・記録の控え：1日の目標、控えの書き出し（スマホは共有シート、パソコンはダウンロード）・読みこみ（同じ記録は新しいほう、ほかは足す）、すべて消す

## 記録の置き場所

この端末（ブラウザ）の localStorage の `shoquji:v1` だけ。ブラウザで開いたしょくじは、サーバーには送らない（LINE の中でつないだときだけ、下の「LINE とつなぐ」）。

- 記録 1件 = `{ id, date: "YYYY-MM-DD", meal: "朝"|"昼"|"夜"|"間食", name, kcal, p, f, c, at, upd }`（数字は入れなかったら null）
- `upd`（最後に直した時刻）と、消した記録の id（`deleted`）は、あとで「自分の GAS につなぐ」ときに、端末とサーバーの記録をそろえるために残している

## LINE とつなぐ（くわしい人向け）

LINE の中（LIFF）で開いたしょくじだけ、自分の食事記録ボット（line-meal-project の GAS。リポジトリは非公開。配布用シートのコピー）とつなげる。つくりは、つづく（q-tuzuq）の「LINE とつなぐ」を写したもの。

- 画面：「⚙️ LINE とつなぐ（くわしい人向け）」のたたみ欄。GAS の URL（`…/exec`）を入れる欄は LINE の中で開いたときだけ出る。形がちがえば赤字。つないでいるあいだは、この日のしょくじの下に「LINE で開いたしょくじの記録は、ブラウザとは別」と出す。LINE のアプリ内のブラウザ（LIFF でない形）で開いたときは「LINE のしょくじで開きなおす」
- 記録すると、ボットのシートにも1行入る（`submitMealBatch`。しょくじの記録の id を `clientId` として送り、同じ id は何度送っても1回だけ）。つながったときに、まだ送っていないここ7日の記録も送る（送った id は `sent`）
- 開いたとき・戻ってきたとき（1分に1回まで）に、ボットに入っている60日分の記録を読む（`listMealLogs`）。しょくじから送ったもの・しょくじで消したものは出さない。ボットのトークで送った記録は「ボット」の札で出す（端末の記録には足さず、控えは `shoquji:bot`）
- 「ボット」の記録を押す・カードの「画面で詳しく」（`logId`）から開くと「ボットの記録を直す」：「✏️ 直す」でボットのその記録を直す（`updateMealLog`。カロリーは要る。MYメニューにも保存）。端末の記録はふやさない
- カードの「MYメニューを直す」（`masterKey`）から開くと「MYメニューを直す」：「📒 MYメニューに保存」で MYメニューだけ保存（`saveNutritionMasterOnly`）
- 送るのは LIFF の ID トークンと記録だけ（userId は送らない。トークンは残さない）。つなぎ先は自分で入れた URL だけ
- LIFF の ID は `js/line-config.js`。食事記録ボットの LIFF（`2010088825-CulmmaFc`。エンドポイントを `https://katsuan.github.io/shoquji/` にする）。この LIFF で開いたときは、つなぎ先を入れなくても食事記録ボットにつながる（`gasUrl`）。ボットのカード・リッチメニューの指定（`?mode=…&meal=…&menu=…&logId=…`）も受ける
- つなぎ方は `docs/linelog-setup.html`（配布用シート「食事記録 しょくじ版（配布用）」のコピーから5手）
- ブラウザで開いたときは、この日のしょくじの下に「💬 LINE で使う」（LINE で開く案内と4コマ。つづくと同じ作り）。閉じたらその端末では出さず、「⚙️ LINE とつなぐ」の「👀 LINE での使い方（4コマ）を見る」でまた出る
- 自分の記録を直す・消すと、ボットにもそろえる（id＝`clientId` で `updateMealLog`・`deleteMealLog`。カロリーがなくてもよい）。消すのは「元に戻す」を押せる6.5秒が過ぎてから送る（閉じる・切りかえるときは、すぐ送る）
- 「ボット」の記録にも ✕。押すと画面から先に消し、「元に戻す」の時間が過ぎてからボットから消す
- 開いたときに、ボットの目標・20時のお知らせ・よく記録するもの・MYメニューを読む（`getLiffAppState`）。目標カロリーはボットの値にそろえ、変えたらボットにも送る（`updateProfile`）。「🔔 20時に、記録がない日は LINE でお知らせ」は「⚙️ 目標・送り方・記録の控え」の中
- 「📌 よく記録するもの（LINE のメニュー）」：固定する品（MYメニューから12品まで）の並べかえと、LINE のリッチメニュー「⚡ よく記録」（画像は `js/meal-richmenu.js` で描く。ボットの GAS の位置とそろえる）。開いたときに、並びが前に描いたものとちがえば、裏で描きなおす。リッチメニューの「📌 並べかえ」（`mode=quick`）はここを開く

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html`・`style.css` | 画面と見た目（スマホ前提。入力欄は 16px 以上、ページにも背景色）。部品（見出しの行・カード・チップ・入力欄・ボタン・開閉・トースト）はおくるんの Q キット（`https://katsuan.github.io/line-share/shared/ui.css`・`ui.js`。使い方はおくるんの README）。`style.css` には、しょくじの色と字（`:root` の `--ls-accent` など）と、しょくじにしかない見た目だけ |
| `app.js` | 操作（記録・直す・消す・カード・ふりかえり・目標・控え） |
| `js/store.js` | 記録の保存・控えの書き出しと読みこみ |
| `js/stats.js` | 計算（日付・合計・よく食べるもの・1週間・続けた日数） |
| `js/meal-richmenu.js` | 食事記録ボットのリッチメニュー「⚡ よく記録」の画像を描く（line-meal-project の html/js/richmenu.js の写し） |
| `js/linelog.js`・`js/line-config.js` | LINE の中で開いたときの、食事記録ボットとのつなぎ（つづくの写し）と、その LIFF の ID |
| `img/meal-richmenu-main.png` | 食事記録ボットの共通のリッチメニュー（「📝 記録」）の画像。ボットの GAS が、メニューを作りなおすときにここから取る |
| `docs/linelog-setup.html` | 自分の食事記録ボットとつなぐ手順と、受け口の約束 |
| `test/` | 控えの読みこみと計算・ボットとのつなぎのテスト（`node --test test/`。`package.json` は node に js/ を読ませるためだけ） |
| `tools/icon.py` | アイコン・ロゴ・OGP |

## アイコン・ロゴ・OGP

`python3 tools/icon.py` で作る（図形を描く部分は、となりのおくるん（`~/GitHub/q-oqrn`）の `tools/brandkit.py`）。

- Q は上から見たお茶碗：白いふちが Q の輪、中にご飯と梅干し、右下へ出た2本のお箸が Q のしっぽ（お皿とお箸・満腹の顔の案とくらべて決めた）
- 横長のロゴ（`logo.svg`）：S・h・o・j・i は Jua、Q はお茶碗、u は 🍵 のような湯のみ（u の字の形を胴にして、緑のお茶と湯気）
- 色は玉子焼きの黄色（ほかの Q のツールと重ならない色）
