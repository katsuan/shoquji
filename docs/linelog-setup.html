しょくじ

自分の食事記録ボットとつなぐ

しょくじは、ふだんは記録をこの端末の中だけに残します。LINE の中で開いたときだけ、自分で用意した GAS（食事記録ボットの配布用シートのコピー）にも記録を入れられます。ボットのトークで送った記録も、しょくじに出ます。

しょくじは、あなたの LINE の鍵を預かりません。送るのは、LINE が出す「本人の確かめ用の印（ID トークン）」と、記録（日付・食事・名前・カロリー・PFC）だけです。印は確かめに使うだけで、しょくじにも GAS にも残りません。

つなぎ方（はじめて）

  1. 配布用シート（食事記録 しょくじ版）を開き、「コピーを作成」（シートについた GAS も一緒にコピーされます。記録はこのシートに入ります）
  2. コピーしたシートの「拡張機能」→「Apps Script」を開き、左の gs/7_setup/7_setup を開いて、上の関数の欄で setupShoquji をえらんで実行（はじめは権限の確認が出ます）
  3. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」、実行するユーザー「自分」、アクセスできるユーザー「全員」→ 出てきた URL（…/exec）をコピー
    （しょくじからの呼び出しは、確かめた本人のものだけ受けます）
  4. LINE の中でしょくじを開き、「⚙️ LINE とつなぐ（くわしい人向け）」に 3 の URL を入れる。「持ち主の登録を受けつけました」と出ます
  5. 10分以内に、同じ 7_setup で adoptShoqujiOwner を実行（実行ログに自分の名前が出ればよい）。しょくじを開きなおすと、記録がシートにも入ります

やめるときは、しょくじの URL の欄を空にし、GAS のデプロイをアーカイブします。

LINE のトークでも記録したいときは、同じ GAS を LINE の Messaging API のボットにつなぎます（くわしくは食事記録ボットの README）。

受け口の約束（GAS を自分で作る人向け）

しょくじは、入れた URL に POST します（本文は text/plain の JSON）。

{ "action": "submitMealBatch", "idToken": "…", "source": "shoquji", "dedupe": false, "sendLineSummary": false,
  "items": [{ "clientId": "lq3x8k2abc", "mealDate": "2026-10-24", "meal": "昼", "menu": "カレーライス", "kcal": 780, "protein": 20, "fat": 25, "carb": 110 }] }
→ { "ok": true, "added": [ … ], "skipped": 0 }

{ "action": "listMealLogs", "idToken": "…", "from": "2026-08-26", "to": "2026-10-24" }
→ { "ok": true, "logs": [{ "logId": "…", "clientId": "…", "date": "2026-10-24", "meal": "その他", "menu": "プリン", "kcal": 200, "protein": null, "fat": null, "carb": null }] }

うまくいかないとき → { "ok": false, "error": "（やさしい言葉）" }
  • 本人の確かめ：POST https://api.line.me/oauth2/v2.1/verify（id_token、client_id＝しょくじの LIFF のチャネル ID）。送られてきた userId は使わない
  • 書く：同じ clientId は何度送られても1件だけ。1回に30件まで。間食は その他
  • 読む：本人の、62日までの記録だけ。ほかの人の記録・userId は返さない
  • 持ち主が決まるまでは何も書かない（持ち主の候補を10分だけ覚え、エディタで adoptShoqujiOwner を実行すると持ち主になる）

URL は秘密ではありません。知られても、確かめなしには何も書けず、何も読めません。ただし、知らない人から渡された URL は入れないでください（入れた先に、確かめ用の印が届きます）。
